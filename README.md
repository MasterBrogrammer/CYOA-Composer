# CYOA Composer

![Preview](preview-thumbnail.jpg)

A simple, browser-based tool for creating illustrated Choose Your Own Adventure stories with support for:

- Images and Videos per passage
- Audio clips (with optional auto-play)
- Branching choices
- Project saving (internal + JSON export)
- Live preview
- One-click HTML export (fully self-contained)

## How to Use

1. Open `cyoa-composer.html` in any modern browser.
2. Follow the built-in tutorial or jump straight into creating your story.
3. Use **Save to Projects** to work on multiple stories.
4. When finished, click **Export HTML** to download a complete, standalone story file.

Everything (images, video, audio) is embedded in the final HTML file — no external dependencies needed.

## Features

- Visual story composer with live preview
- Supports JPG, PNG, WebP, GIF, MP4, WebM
- Per-passage audio with auto-play toggle
- Internal project manager + JSON import/export
- Clean branching system using passage titles

Made for creators who want to build rich, interactive narrative experiences quickly.
